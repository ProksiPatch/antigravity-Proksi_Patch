## ⚡ Основные возможности

* **Полный обход геоблокировок AI:** Google Gemini, Google AI Studio, NotebookLM, Anthropic Claude, OpenAI ChatGPT.
* **Google Antigravity IDE & CLI:** Бесперебойная работа среды разработки и языковых серверов без региональных ошибок (`User location is not supported`).
* **YouTube 4K & Media:** Аппаратный обход замедлений с отсечкой зависающего протокола QUIC (UDP 443).
* **Telegram Desktop & Web:** Обход блокировок дата-центров Telegram (звонки, фото, видео).
* **VirusTotal & Security:** Проверка файлов на `virustotal.com` через чистый европейский маршрут.
* **Раздельное туннелирование (Split Tunneling):** Все российские сайты (Госуслуги, банки, маркетплейсы, VK, Яндекс) и онлайн-игры идут напрямую через вашего домашнего провайдера с максимальной скоростью и нулевым риском бана античитами (BattlEye, EAC, Vanguard).
* **Торрент-фильтрация:** Автоматическое исключение BitTorrent/qBittorrent из туннеля для защиты трафика.
* **Классический тёмный интерфейс в стиле Windows 11 Fluent Dark:** Элегантное меню трея с плавными эффектами.
* **Интеллектуальная диагностика:** Отдельная интерактивная консоль PowerShell с автоматическим распознаванием сетевых кодов ошибок.

## 🚀 Установка в 1 клик

1. Скачайте инсталлятор **[`ProksiFi_v2.0_Setup.exe`](https://github.com/ProksiPatch/antigravity-Proksi_Patch/releases/latest)**.
2. Запустите файл от имени администратора.
3. Нажмите **«Установить»**.
4. Программа автоматически:
   * Развернет компоненты в `C:\Program Files\ProksiFi`.
   * Привяжет устройство по аппаратному HWID к серверу через 3X-UI.
   * Настроит и запустит системную службу `ProksiFiService`.
   * Поместит значок управления в системный трей возле часов Windows.

## 🖥️ Управление из системного трея (Windows 11 Fluent)

Значок защищенного щита в трее возле часов показывает статус соединения:
* 🟢 **Зеленый щит:** Обход активен, служба работает в штатном режиме.
* 🔴 **Красный щит:** Служба остановлена, трафик идет напрямую.
* 🟡 **Желтый щит:** Выполняется проверка или перезапуск службы.

### Меню по правому клику:
* **● СТАТУС:** Текущее состояние подключения и адрес сервера (Франкфурт).
* ⚡ **Включить обход:** Запуск службы маршрутизации.
* ⏸️ **Отключить обход:** Остановка службы и возврат к обычному интернету.
* 🔍 **Тест подключения:** Интерактивное тестирование эндпоинтов Google, Gemini, IP и задержки в окне PowerShell.
* 🔄 **Перезапустить службу:** Быстрый рестарт ядра sing-box.
* 🛠️ **Диагностика системы:** Проверка адаптера ProksiFiTUN, маршрутов, службы и распознавание ошибок.
* 📋 **Журнал событий (Логи):** Просмотр логов в реальном времени с цветовой разметкой.
* 🗑️ **Удалить ProksiFi:** Полная корректная деинсталляция всех компонентов (сам инсталлятор сохраняется).
* 🚪 **Выход:** Закрытие трей-клиента (служба продолжает защищать соединение).
